# abwow-loot-images

PNG icons for Rust loot containers used by Administrator Control Centre.

Direct files:

`https://raw.githubusercontent.com/XXMultitronXX/abwow-loot-images/main/crates/{prefab_shortname}.png`

CDN:

`https://cdn.jsdelivr.net/gh/XXMultitronXX/abwow-loot-images@main/crates/{prefab_shortname}.png`

`{prefab_shortname}` is the prefab file name without `.prefab` (underscores kept), e.g. `loot_barrel_1`, `crate_basic`, `beehive.natural`.
